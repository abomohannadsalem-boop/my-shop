# به‌روزرسانی دسته‌بندی‌ها و چندعکسی محصول

## ۱) اجرای SQL در Supabase

1. از داشبورد پروژه Supabase وارد **SQL Editor** شوید.
2. فایل `supabase/migrations/20261014_phone_case_categories.sql` را باز کنید.
3. تمام محتوای آن را در یک Query جدید قرار دهید و Run کنید.
4. این اسکریپت چهار دسته اصلی و زیر‌دسته‌های اعلام‌شده برای Apple و Samsung را می‌سازد. دسته‌بندی‌های قدیمی نمونه را حذف می‌کند؛ خود محصولات حذف نمی‌شوند، فقط اتصال آن محصولات به دسته‌های قدیمی خالی می‌شود.

## ۲) اجرای پروژه در ویندوز

در PowerShell، داخل پوشه پروژه اجرا کنید:

```powershell
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

## امکانات تغییر داده‌شده

- در پنل `/admin`، وضعیت موجود/ناموجود محصول با تیک «محصول موجود است» قابل تغییر است.
- هنگام ثبت یا ویرایش محصول می‌توانید چند عکس را هم‌زمان انتخاب کنید یا در چند نوبت عکس اضافه کنید.
- عکس‌ها در مرورگر به WebP تبدیل و در Supabase Storage بارگذاری می‌شوند.
- برای هر محصول عکس‌ها در گالری صفحه جزئیات نمایش داده می‌شوند؛ در کارت محصولات فقط عکس اول نمایش داده می‌شود.
- دسته‌بندی‌ها سلسله‌مراتبی شده‌اند: چهار دسته اصلی، مدل‌های Apple و Samsung، و دسته‌های خالی Xiaomi و سایر گوشی‌ها برای تکمیل بعدی.

## افزودن مدل‌های بیشتر

برای افزودن مدل گوشی جدید، در SQL Editor یک ردیف به جدول `categories` اضافه کنید و `parent_id` را برابر شناسه دسته اصلی مربوط قرار دهید. می‌توانید شناسه دسته‌ها را با این کوئری ببینید:

```sql
select id, name, slug, parent_id from public.categories order by parent_id nulls first, name;
```

> فایل `.env.local` باید در پوشه اصلی پروژه بماند و نباید عمومی منتشر شود. هرگز کلید `service_role` را در کد سمت مرورگر قرار ندهید.


تغییرات نسخه هدر و ذخیره: دسته‌های اصلی در هدر نمایش داده می‌شوند و زیر‌دسته‌ها پس از کلیک تا ۶ ثانیه باز می‌مانند و سپس محو می‌شوند. ذخیره محصول فقط به جدول products متکی است تا خطای سیاست جدول اختیاری product_media پیام اشتباه «ذخیره انجام نشد» ایجاد نکند؛ گالری از image_url استفاده می‌کند.
